let vs var scope

Unit: Variables and Assignment

Step 1 of 4 25% Complete
lightbulb

Key Idea: Scope Difference

var is function-scoped, meaning it is accessible throughout the entire function it's defined in. let is block-scoped, restricted strictly to the nearest curly braces {}.

Example Snippet
01 if (true) {
02 var x = 5;
03 let y = 10;
04 }
05 console.log(x); // Output: 5
06 console.log(y); // ReferenceError: y is not defined
info Result: 'y' is trapped inside the block scope and cannot be reached externally.

quiz Quick Check

What will be printed if we try to access 'y' outside the if-statement in the example above?

verified

Correct!

Since 'let' creates a block scope, 'y' only exists inside the if-block. Attempting to log it outside triggers an error.
